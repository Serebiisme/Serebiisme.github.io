01 / WHY NORMALIZE

两种分数，
不能直接比大小。

RAG 混合检索会同时拿到 BM25 的关键词匹配分与向量相似度。它们的数值范围不同：例如 BM25 是 12.3，向量分是 0.82。直接相加时，即便权重各为一半，BM25 的数值仍会占据绝大部分。

看一个更完整的例子。三篇候选文档的原始分数如下；两列分别做 Min-Max，然后各取 50% 权重：

C2.00.552.550.163

原始相加会让 A 胜出；放到各自的 0–1 尺子后，B 的向量优势终于能发挥作用。等权重只有在分数尺度可比时才接近“各占一半”。这里的数字只是演示，实际排名还取决于候选集和融合策略。

02 / TWO MOVES

平移到零，
缩放到一。

Min-Max 归一化只有一个公式。先减去最小值，消除整组数字的偏移；再除以极差，把最大值压到 1。

(x − min) / (max − min)

拿 [2, 5, 8] 走一遍：最小值是 2，最大值是 8，极差是 6。

03 / PRESERVE THE SHAPE

尺子变了，
相对距离没变。

原来的 2 → 5 → 8，相邻两段各差 3；映射后的 0 → 0.5 → 1，相邻两段各差 0.5。两段的比例始终是 1 : 1。

这也是它的限制：一个极端最大值会拉大整条尺子，使普通值之间的距离在 0–1 区间里显得非常小。

04 / TWO GUARDS

公式之外，
还要照顾特殊输入。

GUARD 01 / 空数组

[] → []

直接返回空数组。否则 Math.min(...[]) 会得到 Infinity，后续计算没有意义。

GUARD 02 / 所有值相同

[5,5,5] → [0,0,0]

此时 max − min = 0。把分母设为 (max − min) || 1，避免除以零；每个分子也都是 0。

第二个处理是实现约定：当所有候选值一样，这个维度没有区分力，统一归零。它不代表原始分数本身是零。

把输入换成 [2, 5, 8, 100]。Min-Max 以 100 为最大值时，前三个普通值会被挤到 0 附近。Sigmoid 则用 S 曲线做有界的“软压缩”：极端值靠近 1，但不强迫其他点挤在起点。

06 / TAKEAWAY

记住这一句，
就抓住了核心。

The short version
“平移到零、缩放到一。”
  • 目的：把不同量纲的检索分数放在可比尺度上，再做加权融合。
  • 公式：(x − min) / (max − min)，保持顺序与间距比例。
  • 边界：空数组返回 []；极差为零时分母取 1，结果全为 0。
  • 取舍：Min-Max 对离群值敏感；Sigmoid 能软压缩，但需要选择中心和尺度。
