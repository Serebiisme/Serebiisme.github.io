01 / THE FORMULA

任意输入，
落在 0 与 1 之间。

σ(x) = 1 / (1 + e−x)

这就是 Sigmoid，也叫 Logistic 函数。对任何有限实数 x，数学上的输出严格在开区间 (0, 1) 内。它始终递增，却永远不会在有限输入处真正碰到 0 或 1。

中点 / x = 0

σ(0) = 0.5

因为 e⁰ = 1，所以 1 / (1 + 1) = 0.5。输入 0 固定落在正中间。

两端 / x → ±∞

0 < σ(x) < 1

x 越大，输出越接近 1；越小，越接近 0。两端是渐近线。

03 / THE S CURVE

两头平，
中间最敏感。

左边贴近 0，右边贴近 1，中间穿过 (0, 0.5)。这三个区域连起来，就是字母 S 的轮廓。

左侧 / 贴近 0

−10 → −8

输出约从 0.000045 到 0.000335。输入变了 2，输出只变约 0.000290。

右侧 / 贴近 1

8 → 10

输出约从 0.999665 到 0.999955，变化同样很小。

中间则不同：σ(−1) ≈ 0.269、σ(0) = 0.5、σ(1) ≈ 0.731。每增加 1，输出变化约 0.23，明显大于两端。

04 / MIN-MAX VS SIGMOID

一条直线，
一条 S 曲线。

特性Min-Max原始 Sigmoid σ(x)
变换线性非线性，单调递增
数学输出[0, 1]，包含端点(0, 1)，不含端点
所需信息当前候选集的 min 和 max只需要当前输入 x
新值加入可能改变旧值结果固定函数下，旧值结果不变
离群值可能挤压普通值极端输入在尾部饱和

例如已有 [2, 5, 8]，Min-Max 把 5 映射为 0.5；加入 100 后，同一个 5 变成 3 / 98 ≈ 0.031。原始 Sigmoid 的 σ(5) ≈ 0.993307 在两批数据里完全相同。

05 / RAG PRACTICE

BM25 是正数时，
别忘了校准。

许多 BM25 实现会给出非负分数。若直接套 σ(x)，正数只落在 (0.5, 1)，较大的分数会迅速挤向 1：σ(2) ≈ 0.881、σ(5) ≈ 0.993、σ(8) ≈ 0.9997。这会让高分之间难以区分。

BM25 输入258
直接用 σ(x)0.8810.9930.9997
固定校准 σ((x−5)/3)0.2690.5000.731

一个可选做法是先用固定的中心与尺度把输入移到 Sigmoid 的中段，例如上表中的中心 5、尺度 3。这些数只是说明原理，真实参数需要按检索分数分布校准。若中心和尺度改为从当前候选集临时计算，输出又会依赖其他文档。

站点没有提供 normalizeViaSigmoid 的源码，因此这里解释的是你给出的标准公式，不推断项目函数实际采用了哪种校准。

06 / TAKEAWAY

记住这条曲线
的脾气。

The short version
“中间分得开，两端收得住。”
  • 公式：1 / (1 + e−x)，把实数压进 (0, 1)。
  • 形状：x = 0 时为 0.5；两端饱和，中间相对敏感。
  • 优势：固定函数逐点计算，新文档不会改变旧分数。
  • 注意：正数直接输入只用到上半区；实际融合前要检查校准效果。
