## 审查与修复

一次独立整分支审查，没有 Critical；两个 Important 为并发保存误删完整缓存与 ZIP 更新被旧缓存遮蔽。已通过 RED→GREEN 修复：新包串行化、失败不删除其他 worker 完成的包、旧 worker 只清理开始前存在的版本；显式 ZIP reload 获取新网络字节，断网保留已保存版本。整套测试通过。

升级回归还发现旧页面绑定与等待 worker 的生命周期问题：安装中等待 `skipWaiting` 调用完成，客户端明确激活 waiting worker、查询新注册状态，并按版本刷新页面一次。不清理课程缓存或阅读进度；一次刷新可能重置未提交的测验输入。

安全通用扫描命中四处同一 AWS 官方示例标识（原始文件、展示文件、代码块及 ZIP）。已核对 [AWS 官方文档](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_credentials_access-keys.html)，只允许指定原始文件完整哈希及其精确衍生位置，不允许其他文件或其他 credential-shaped 字符串。专用扫描器同时展开全部 604 个 ZIP；未批准匹配为零。不是忽略通用警告。本轮新锁文件和脚本不带内部 npm 镜像或本机用户路径；131 个依赖包的完整性哈希与公开 npm 注册表逐项一致。此前已发布的其他文档保持不改。

## 实施取舍（含风险）

1. 原测验同时有数组与对象格式；原始文件不改，消费层归一化。若判断错，会遗漏真实测验；两类格式都已测试。
2. 77 份项目清单包含一个 authoring template；按 76 个正式项目展示。若判断错，会漏项目；已核对其余均 ready。
3. 自定义交互图采用隔离、断网构建的静态快照；网页不运行上游图解 JS。风险是缺少滑块、动画和中间状态，图注明确说明。
4. Mermaid 含 @ 的节点标签仅在渲染输入中加引号，原始 Markdown 不动。风险是视觉换行可能不同，文字和边不改。
5. 读者/分包/课程库关联接口一起实现；包注册生成整合在渲染构建器以追踪实际依赖。风险是审查单位较大，未来独立复用需提取内部函数；对应失败测试与整体验证保留。
6. 精确处理哈希验证的 AWS 公共示例，不作宽泛示例白名单。判断错会暴露凭证；以完整哈希、限定位置和官方文档降低风险。
7. 525 草稿未经语言质量审查；按用户明确批准发布，并保留英文全文和警告。风险是读者误信翻译。
8. 练习代码执行正确性未验证。风险是依赖或环境不兼容，所有页面和 ZIP 均说明运行未验证。
9. 未逐张复核所有图的视觉忠实度；全部非空渲染并抽样检查。风险是静态图缺少有用中间状态，原文链接保留。
10. 部署行为与旧版升级不被豁免；只有实际本地/公共验证才能声称上线。否则风险是旧客户端不可访问。
11. 升级旧页面在 worker 激活后按版本刷新一次，保留缓存和进度。风险是未提交的测验输入重置；已测试不进入刷新循环。
12. 仅整理本轮最后一个未推送功能提交的私有镜像地址和本机路径，其他提交保持不变，正常快进推送。风险是本地审查 SHA 改变；原检查点在 reflog 与审查包中可恢复。
13. 本次核验发现已安装 Playwright 的异步谓词被当作 truthy Promise，导致首次线上保存检查提前结束；改为显式等待 `page.evaluate` 的布尔结果，并等待进度恢复后的真实页面状态。风险是核验误报通过；两项真实浏览器回归先失败再通过，修正后重跑完整本地升级与线上验证，不改产品阅读器/worker。
14. 公共 CDN 顺序下载在测试的 15 分钟总时限时到达第 11 阶段，没有产品保存失败；公共核验改用八个独立标签页点击真实保存按钮，每包保留 15 分钟预算，不直接填测试缓存。本地仍验证一键保存全部。风险是未实测线上一键下载的完整耗时；所有包的公网下载、缓存完整性及断网页面覆盖仍核验。
15. 约 9.8 MB 的搜索索引冷加载使用 180 秒等待预算；线上明确出现的 HTTP 503 或 Cache.put 的网络传输中断最多通过页面按钮重试两次，每次写入报告，其他错误不重试。风险是公网可用性和初次加载速度不稳定，需要重试；不承诺首次下载永不失败，不豁免缓存完整性和断网检查。
16. 公共测试浏览器缓存仅在隔离测试目录保留，目录按全部阅读包版本指纹分开；复测仍通过真实按钮重新检查清单和完整性，并用独立空白上下文检查未保存时的回退。风险是热缓存可能掩盖冷网络问题；首次实际下载记录保留，版本变化使用新目录，不触碰用户浏览器，不直接写入测试缓存。
