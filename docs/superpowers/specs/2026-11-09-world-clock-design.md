# 北京此刻 · 世界时钟

用户要求实现城市时间对照应用并发布到现有 GitHub Pages。本次沿用专用目录直接实施、主分支发布的会话授权；以下未指定细节是实现取舍，不声称用户逐项确认。

## 目标与选择

以北京时间为固定原点，查看世界城市同一时刻的当地时间；可选择一个北京时间进行换算。候选为纯静态 Intl 应用、外部时间 API、重型世界地图。选择纯静态应用：适合当前 Pages，无账号、密钥或外部运行时资源；不增加地图和服务器。

## 界面

沿用整站编辑式新粗野主义：纸色 #f4f1ea、黑色 #191919、浅蓝 #c7d6ee、珊瑚 #f3c8bb、绿 #d6e3bc、黄 #f8e6a9、紫 #ded4ee。系统中文无衬线标题，等宽数字，细描边与硬阴影。

上方为标题和说明；中间左侧固定北京大时钟，右侧日期时间换算、24 小时滑块及回到现在/复制按钮；下方是城市卡片与添加城市入口。城市显示当地日期、24 小时时间、UTC 偏移、相对北京的时差、跨日关系和时段。时段指钟表小时，不代表天文日出日落。

默认东京、新加坡、迪拜、伦敦、纽约、洛杉矶、悉尼；可搜索中文、英文与浏览器列举的 IANA 地区时区，增删最多 24 个对照城市。目录不承诺所有可被 Intl 接受的别名或 UTC 搜索。城市偏好仅保存在本机，存储受限时仍可使用。所有卡片使用同一时间戳；实时模式每秒从设备时钟重新读取，不累计计时。

日期输入明确为北京时间 UTC+08:00，范围 2000–2099，拒绝无效日期。当地时间按所选日期的时区规则计算，正确处理夏令时、半小时/45 分钟偏移、跨日与跨年。准确性取决于设备时间和浏览器时区数据更新，不是网络授时。
