主指南 / Claude Code for Product Work

用 Claude Code 完成产品工作

从文件协作和用户研究出发，练习 PRD、数据、策略、视觉与原型交付。

8 节 · 建议练习时间 355 分钟 · 已完成 0/8

本地讲解与练习可缓存；运行 AI 和访问参考外链仍需联网。

学完要能做到

  • 建立可追溯、可恢复的产品工作区
  • 把访谈与小型数据集转化为有边界的判断
  • 写出包含异常路径和验收标准的需求
  • 完成可评审的视觉方案与原型交付

主题参考：主题目录参考：Free AI Courses / Claude Code for Product Managers ↗。下面是本站重新组织的原创学习单元，不与原课程章节逐一对应。

01

先认清工作区，再允许改文件

让第一次文件任务留下清楚的输入、输出与修改范围。

35 分钟 →02

把研究材料整理成证据链

区分原话、解释与产品假设，让综合结论接受抽查。

45 分钟 →03

把分工和记忆写成可维护约定

让代理独立处理明确任务，并让长期背景保持准确。

40 分钟 →04

把 PRD 写成团队能作决定的文档

从问题与证据出发，补齐规则、异常路径和验收。

50 分钟 →05

先手算小样本，再解释产品数据

核对口径、分母与分组，避免用整齐图表掩盖推断错误。

45 分钟 →06

让策略产生选择和停止条件

把资料整理为约束下的选项，形成可解释的产品取舍。

45 分钟 →07

用 Nano Banana 视觉简报建立一致性

写清视觉用途、结构和风格，保留评审标准而不依赖偶然好图。

40 分钟 →08

把原型、Git 和发布连成可检查交付

用最小原型验证任务，并在公开发布前明确版本和影响。

55 分钟 →
