01AI 工程中的嵌入是什么？中文解析

原题 / What are embeddings in the context of AI engineering?

原理与边界

嵌入将文本、图像或其他对象映射为向量，使模型或检索系统能比较表示。距离表达训练目标下的相关性，不能视为事实相同或置信概率。token 嵌入与检索句向量用途不同；选择表示、预处理和相似度指标时，应围绕具体任务验证。

02嵌入模型怎样把文本转换为向量？中文解析

原题 / How do embedding models convert text to vectors?

原理与边界

文本先经分词和编码网络获得 token 表示，再通过池化、投影或特定位置生成固定长度向量，可能再归一化。检索模型还需训练目标让查询和文档的表示可匹配。不同模型的向量空间不可直接互换；长度截断、任务前缀与池化方式会影响结果。

03什么是对比学习？怎样训练嵌入模型？中文解析

原题 / What is Contrastive Learning, and how is it used to train embedding models?

原理与边界

对比学习让相关样本比负样本更接近，例如以查询、相关文档和无关文档训练相似度排序。损失可用成对、三元组或批内对比形式。负样本选择影响难度，误把相关文档当负例会伤害表示；温度、批次和难负例都需按实际检索任务验证。

04稀疏与稠密嵌入有何区别？中文解析

原题 / What is the difference between sparse and dense embeddings?

原理与边界

稀疏表示在大词表空间中仅少量维度非零，可对应词项或学习到的词权重；稠密表示在较低维空间中多数维度有值。前者擅长保留词项匹配，后者可表达语义联系。稀疏并不一定是传统关键词统计，稠密也不保证理解型号、数字和否定关系。

05余弦相似度、点积与欧氏距离怎样用于向量搜索？中文解析

原题 / Explain cosine similarity, dot product, and Euclidean distance for vector search.

原理与边界

余弦只比较方向，点积同时受方向与向量范数影响，欧氏距离比较坐标差异。单位归一化时，点积等于余弦，平方欧氏距离为 2−2×点积，因此排序可一致。未归一化时不能混用；索引度量要与模型训练及预处理匹配，分数不是相关概率。

07近似最近邻（ANN）搜索怎样工作？中文解析

原题 / How does Approximate Nearest Neighbor (ANN) search work?

原理与边界

ANN 通过图遍历、聚类分区或压缩等方法减少需要精确计算的候选，再返回近似最近邻。它用部分召回损失交换延迟与资源节省，并非保证找到全部真邻居。用精确搜索作为基准测 recall@k，调搜索宽度与索引参数，还要测试过滤后的结果。

08怎样比较 HNSW、IVF 与 Flat 索引？召回率如何影响延迟？中文解析

原题 / Compare HNSW, IVF, and flat indexes. How do you pick one, and what does recall@k cost in latency?

原理与边界

Flat 扫描所有向量，结果精确但成本随规模增长；HNSW 遍历分层邻接图，搜索宽度影响召回和延迟；IVF 先选聚类分区，探测分区数影响候选量。提高 efSearch 或 nprobe 通常增加工作量，收益取决于数据与过滤，应在目标硬件测召回—延迟曲线。

09嵌入缓存怎样工作？中文解析

原题 / How does an Embedding Cache work?

原理与边界

缓存按文本内容及模型版本、编码配置保存已计算向量，相同输入可直接复用。缓存键应覆盖前缀、归一化和截断等会改变结果的配置，必要时加入租户隔离。它节省编码调用，不是复用生成答案的语义缓存；哈希可能碰撞，TTL 也不能保证不同空间兼容。

11嵌入维度是什么？怎样影响表现和成本？中文解析

原题 / What is embedding dimensionality, and how does it affect performance and cost?

原理与边界

12嵌入模型更新后，怎样处理表示漂移？中文解析

原题 / How do you handle embedding drift when the embedding model is updated?

原理与边界

把模型版本、维度、度量和预处理作为索引契约，新模型通常形成新空间，旧文档向量需重新编码。建立新索引并双跑真实查询，验证质量与覆盖后切流，保留旧版本回滚。即使维度相同也不意味着空间兼容，不能只更新查询编码器而继续使用旧文档。

短查询信息少，易有实体歧义或缺乏语境。可结合用户当前任务做受控扩展，加入关键词检索、领域词典和查询重写，再重排候选；关键信息缺失时应请求澄清。扩展不能虚构意图，多路查询要保留原查询并评价误召回，避免一味增加文本长度。
