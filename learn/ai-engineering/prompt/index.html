原题 / What is prompt engineering, and why is it critical for AI applications?

原理与边界

02零样本、单样本与少样本提示有什么区别？中文解析

原题 / Explain zero-shot, one-shot, and few-shot prompting with examples.

原理与边界

零样本只描述任务；单样本给一个示例；少样本给多个示例。示例同时传递标签、格式和判断边界，但会占用上下文并引入偏差。应覆盖易混淆案例，避免示例泄露测试答案。

03思维链提示（CoT）是什么？何时使用？中文解析

原题 / What is chain-of-thought (CoT) prompting, and when should you use it?

原理与边界

CoT 用中间步骤帮助处理多步问题。收益取决于模型和任务，并非所有模型都需要显式要求展示推理。步骤写得像推理不代表正确；应用可要求简短可核验依据，而不依赖隐藏思考文本。

04自一致性提示怎样改进推理？中文解析

原题 / Explain self-consistency prompting and how it improves reasoning.

原理与边界

对同一问题采样多个解题路径，再按答案聚合，例如多数投票。它用额外计算减少单次采样偶然误差，但路径可能相关地犯同一错误。应记录投票分歧，并允许没有可靠共识时拒答。

06ReAct 如何结合推理与行动？中文解析

原题 / What is ReAct (Reasoning + Acting) prompting, and how does it work?

原理与边界

ReAct 交替进行任务判断、工具行动和结果观察，再决定下一步。工具由程序执行，模型的意图文本不等于行动已成功。需要限制步数、验证工具参数，并根据真实返回结果更新状态。

07系统提示词如何影响模型行为？中文解析

原题 / What is a system prompt, and how does it influence model behavior?

原理与边界

系统提示词在应用中设定长期任务与规则，通常位于高优先级消息层。模型仍可能误解或受输入干扰；消息层级不等于强制权限机制。保密、授权和副作用控制应在程序层执行。

09什么是提示注入？怎样防御？中文解析

原题 / What is prompt injection, and how do you defend against it?

原理与边界

攻击者把指令藏在输入、文档或工具返回中，诱导模型改变任务或越权。将外部材料视为数据，限制工具权限、隔离敏感信息，并在执行层验证操作。单靠一句“忽略恶意指令”无法建立安全边界。

11怎样优化提示词的成本与延迟？中文解析

原题 / How do you optimize prompts for cost and latency?

原理与边界

12提示词工程与 Prompt Tuning 有何区别？中文解析

原题 / What is the difference between prompt engineering and prompt tuning?

原理与边界

提示词工程修改可读输入；Prompt Tuning 通常训练连续的软提示参数，在基础模型之外学习适配表示。后者需要训练流程与兼容的模型接口。术语有不同用法，讨论前先明确是否更新参数。

16怎样设计复杂任务的提示链？中文解析

原题 / What is prompt chaining, and how do you design a chain of prompts for complex tasks?

原理与边界

把任务拆成输入输出明确的步骤，给每步设置校验、超时和失败恢复。拆分可提高可观测性，但会增加延迟、成本和错误传播。传递结构化中间结果，并保留来源，不依赖未经检查的自由文本。

21什么是长上下文中的“中间丢失”？中文解析

原题 / What is the "lost in the middle" problem in long-context prompting?

原理与边界

部分模型对材料中部的证据利用较差，位置改变会影响回答。这是实测现象，不是所有模型统一的定律。可重排证据、减少干扰或检索关键片段，并按位置检查多证据任务。

22输出解析器为什么重要？中文解析

原题 / What are output parsers, and why are they needed for production applications?
