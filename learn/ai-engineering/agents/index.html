原题 / What is an AI agent, and how does it differ from a simple LLM call?

原理与边界

Agent 在运行环境中读取目标与状态，选择行动，再依据工具结果继续或结束；单次 LLM 调用通常只产生一次输出。模型提出动作，程序实际执行。是否需要长期记忆或多个模型取决于任务，不能把教学组件清单当作所有 Agent 的必要定义。

06什么是 Plan-and-Execute Agent 模式？中文解析

原题 / What is the Plan-and-Execute agent pattern?

原理与边界

该模式先由规划器拆解目标，再由执行器逐项完成；观察与计划不符时可重新规划。它适合有明确依赖的长任务，便于分配资源与检查进度，但初始错误会沿计划传播，计划维护也有成本。规划器与执行器可以使用同一模型，强弱模型分工不是必要条件。

08结构化输出与函数调用有何区别？中文解析

原题 / What is the difference between structured output and function calling?

53LangGraph 怎样工作？中文解析

原题 / How does LangGraph work?

原理与边界

LangGraph 以状态、节点和边描述可循环工作流，节点返回部分更新，边决定后续执行，reducer 定义状态合并。检查点支持恢复和人工介入，但恢复可能重新执行节点，外部副作用必须幂等。并行分支也需明确更新规则，不能假设所有状态自动安全合并。

54什么是 OKF（Open Knowledge Format）？中文解析

原题 / What is OKF (Open Knowledge Format)?

原理与边界

OKF 用 Markdown 正文与 YAML frontmatter 表示组织知识，将概念文件、索引和链接组成可携带的知识目录。它描述数据和系统的含义，可供人或 Agent 阅读，不直接提供数据库权限。规范持续演进，应按版本检查字段和来源；统一格式不会保证内容真实或及时。
