02全量微调与参数高效微调（PEFT）有何区别？中文解析

原题 / Explain the difference between full fine-tuning and parameter-efficient fine-tuning (PEFT).

原理与边界

全量微调更新全部或大量模型权重，表达能力强，但梯度与优化器状态占用大。PEFT 冻结大部分权重，只训练适配器、低秩更新或软提示，降低训练状态和版本存储成本。PEFT 仍需要基座推理与反向传播相关计算，不能把可训练参数比例直接当作算力节省比例。

03LoRA（低秩适配）是什么？怎样工作？中文解析

原题 / What is LoRA (Low-Rank Adaptation), and how does it work?

原理与边界

LoRA 冻结原矩阵 W，通过两个小矩阵学习低秩增量 ΔW=BA，并按缩放系数加入前向计算。若 W 为 d×k，增量参数约为 r(d+k)，远少于 dk。秩和目标层决定容量与成本；兼容条件满足时可合并增量以减少推理开销，但质量仍需任务评估。

04QLoRA 是什么？怎样在消费级硬件上微调？中文解析

原题 / What is QLoRA, and how does it enable fine-tuning on consumer hardware?

原理与边界

QLoRA 将冻结基座以低比特表示保存，计算时使用较高精度，并训练 LoRA 增量。原方法结合 NF4、双重量化和分页优化器降低显存压力。低比特基座不是所有训练状态都只有四位，激活、适配器和反量化仍占空间；可训练规模还取决于序列长度与批次。

05微调具体怎样工作？中文解析

原题 / How does fine-tuning work?

原理与边界

将样例编码为模型输入与目标，执行前向计算得到预测，按监督目标计算损失，再反向传播并更新允许训练的参数。聊天微调需正确套用模板和损失掩码，避免训练模型模仿用户文本。训练损失下降不能证明泛化改善，应在隔离测试集检查质量和原能力。

06Prefix Tuning 与 Prompt Tuning 是什么？和 LoRA 有何区别？中文解析

原题 / Explain Prefix Tuning and Prompt Tuning. How are they different from LoRA?

原理与边界

Prompt Tuning 通常训练输入端的连续软提示；Prefix Tuning 为多个层提供可训练前缀表示，常体现为额外 K/V。二者冻结基座，通过增加条件表示改变行为；LoRA 则学习权重的低秩增量。前缀会占用注意力资源，训练虽省参数状态，仍需传播梯度。

08预训练、监督微调（SFT）与偏好优化（RLHF/DPO）有何区别？中文解析

原题 / Explain the difference between pre-training, supervised fine-tuning (SFT), and preference optimization (RLHF/DPO).

原理与边界

14什么是灾难性遗忘？微调时怎样预防？中文解析

原题 / What is catastrophic forgetting, and how do you prevent it during fine-tuning?

原理与边界

模型针对新分布更新后，旧任务能力明显下降，称为灾难性遗忘。可用较低学习率、较少更新、混合旧任务样本、参数约束或可切换适配器减少影响。冻结基座不等于启用适配器时完全保留能力；要同时评估新旧任务，用实际退化判断而非只看训练损失。

18学习率、轮数、批次和 LoRA 秩等超参数有什么作用？中文解析

原题 / What are the key hyperparameters for fine-tuning (learning rate, epochs, batch size, LoRA rank)?
