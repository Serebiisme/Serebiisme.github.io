01怎样评估 AI Agent？中文解析

原题 / AI Agent Evaluation

原理与边界

Agent 评估要同时检查最终业务状态和行动轨迹：任务是否完成、工具参数是否正确、是否越权，以及失败后能否恢复。只看最后一句回答会漏掉重复写入和错误动作。使用可重置的环境与固定任务，记录成功率、步骤、费用和延迟，再按失败类型分析。

03什么是 AI Agent 可观测性？中文解析

原题 / AI Agent Observability

原理与边界

04AI 应用中的评估驱动开发是什么？中文解析

原题 / What is evaluation-driven development for AI applications?

05为什么 AI 的表现依赖我们怎样定义“完成”？中文解析

原题 / Why is AI only as good as our definition of done?

原理与边界

完成标准把模糊目标转换为可验证结果，例如功能可用、边界条件通过、权限正确和延迟达标。验证器给 Agent 提供纠错信号，但它只能覆盖已表达的要求。编译成功或单个测试通过都不是完整正确性，模型能力与评测覆盖仍共同决定交付质量。

07解释 BLEU、ROUGE 和 BERTScore，分别何时使用？中文解析

原题 / Explain BLEU, ROUGE, and BERTScore. When would you use each?

原理与边界

BLEU 主要衡量候选与参考的 n-gram 精确匹配并惩罚过短输出；ROUGE 常衡量覆盖，具体看 n-gram 或最长公共子序列变体；BERTScore 用上下文表示匹配 token。它们适合辅助比较，但同义改写、否定和事实错误可能误导分数，不能直接代表用户满意度。

11什么是红队，怎样对 LLM 应用做红队测试？中文解析

原题 / What is red teaming, and how do you red team an LLM application?

原理与边界

13AI 系统的对抗测试是什么？中文解析

原题 / What is adversarial testing for AI systems?

原理与边界
